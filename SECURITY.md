# Security Policy

Please do not publish credentials, private audio, tokens, webhook secrets, Feishu app secrets, local environment files, cookies, or sensitive logs in issues or pull requests.

For a suspected vulnerability, contact the maintainer privately through the contact method on the GitHub profile and include:

- affected version or commit;
- reproduction steps;
- impact;
- suggested mitigation, if known.

Do not include third-party personal data or copyrighted source audio in a public report.
